🎵 Music Studio Manager
📌 Descripción del proyecto

Music Studio Manager es una aplicación web full-stack desarrollada para facilitar la administración de un estudio de enseñanza musical. El proyecto permite al profesor gestionar estudiantes, organizar clases, registrar pagos y consultar información relevante desde un dashboard centralizado.
La aplicación surge de una necesidad real: administrar de forma más organizada la información de estudiantes, fechas de clases, cantidad de horas tomadas y pagos realizados, evitando depender de diferentes herramientas o registros manuales.
El objetivo es transformar este proceso administrativo en una plataforma sencilla, visual y responsive que permita al profesor tener toda la información de su estudio en un solo lugar.

🎯 ¿Por qué se creó este proyecto?

La idea de Music Studio Manager nace a partir de la experiencia de administrar estudiantes de música que tienen diferentes horarios, fechas de pago y cantidad de clases.
Cuando la información se lleva manualmente, puede resultar difícil responder rápidamente preguntas como:

¿Cuántos estudiantes activos hay?
¿Qué clases están programadas esta semana?
¿Qué estudiantes tienen pagos pendientes?
¿Cuántas clases ha tomado cada estudiante?
¿Cuánto dinero se ha recibido durante un período?
¿Cuándo fue el último pago de un estudiante?
¿Qué clases están pendientes o ya fueron completadas?

Por esta razón, el proyecto busca centralizar esta información y convertirla en una herramienta de gestión para profesores independientes o pequeños estudios musicales.

🎯 Objetivo

El objetivo principal es desarrollar una aplicación full-stack, funcional y responsive que permita administrar las principales actividades de un estudio musical desde una única plataforma.
El sistema permitirá:

Administrar estudiantes.
Registrar y modificar información de estudiantes.
Programar clases.
Registrar clases realizadas.
Llevar un historial de clases.
Registrar pagos.
Consultar pagos pendientes.
Visualizar estadísticas generales.
Proteger determinadas rutas mediante autenticación.
Diferenciar el acceso según el tipo de usuario.

Además del objetivo funcional, este proyecto busca demostrar la evolución de mis habilidades como desarrolladora web, integrando conocimientos de frontend, backend, bases de datos, autenticación, APIs REST y diseño responsive.
